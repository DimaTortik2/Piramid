## 1. Стилизация текста
Обычный текст может быть жирным (или таким), курсивным (или таким) и даже жирным курсивом.
Если нужно что-то исправить, используйте зачеркнутый текст. [1, 4] 

Это блок цитаты. Он отлично подходит для выделения важных мыслей или реплик персонажей.
Внутри цитаты можно использовать форматирование.

## 2. Списки

## Маркированный список

* Первый элемент
* Второй элемент
* Вложенный элемент первого уровня
   * Еще один вложенный элемент [1] 
* Третий элемент

## Нумерованный список

   1. Открыть редактор
   2. Вставить этот текст
   3. Посмотреть на результат

## Чек-лист (список задач)

* Проверить отображение чек-боксов
